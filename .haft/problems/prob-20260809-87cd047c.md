# /ps --seo is prose-only; agents skip ps-seo before humanize even when the flag is set

## Signal

Shipped /ps --seo inserts ps-seo between sharpen and humanize by skill prose only (dec-20260804-e3234e50). There is no durable piece mark and no MCP gate: save_humanize_bundle succeeds from sharpen.md whether or not seo.md exists. Latest operator dogfood/tests show agents skip ps-seo even when --seo was given — same failure class as research being skipped under soft MUST. Sibling decision dec-20260809-3a372a15 already bound piece requires_research + draft-owned hard gate for --research; --seo needs the same shape of hard gate so opt-in SEO cannot be skipped into humanize/export.

## Problem Type

synthesis

## Constraints

- Default /ps without --seo must stay SEO-free (dec-20260804-e3234e50 invariant)
- SEO before humanize ordering must hold — never after humanize
- Reuse existing /ps-seo + save_seo_bundle; no second SEO implementation
- Hard gate must be machine-enforced (MCP), not prose-only — admissibility from research DRR pattern
- Do not reintroduce AI-detector-evasion into humanize
- Transformer Mandate: explore then manual /h-decide; do not silently amend dec-20260804 without explicit binding

## Optimization Targets

- MUST semantics for --seo survive agent skip pressure
- Align gate shape with requires_research / draft gate (dec-20260809-3a372a15) so operators learn one pattern

## Observation Indicators

- Whether a generic stage-precondition substrate should land in the same change or later
- Export-path bypass if humanize is skipped entirely on a marked piece

## Acceptance

With /ps --seo, a durable requires_seo (or equivalent) is set on the piece; save_humanize_bundle fails closed until seo.md exists from a successful save_seo_bundle; without --seo, humanize/export behavior stays as today (sharpen→humanize, no seo.md required). /ps still orders SEO before humanize (dec-20260804-e3234e50). Documented in ps/SKILL.md, ps-humanize/SKILL.md, docs/pipeline.md. Verifiable by Go test (marked piece, no seo.md → humanize save error; after seo.md → success) plus skill chain wording.
