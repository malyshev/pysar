# Template application flow: skip per-field walkthrough, fine-tune only on re-run

## Signal

Current /ps-voice and /ps-style Step 1a behavior, once a template is selected, still walks through every field conversationally ("still actually have the conversation -- confirm each field feels right for them... Treat the template as a first draft you're editing together, not a form to auto-submit"). Operator finds this unwanted friction: they want template selection to be a fast, low-friction apply -- not a full re-interview -- with fine-tuning available only later, by re-running the skill on an already-set-up profile (the existing Step 1 re-tune flow). Requested symmetrically for both /ps-voice and /ps-style.

## Problem Type

synthesis

## Constraints

- Must never silently adopt/save a template without the author seeing what will be saved and having a chance to change it -- an explicit What-NOT-to-do invariant already established in both skills
- Must apply identically to /ps-voice and /ps-style -- operator explicitly requested symmetric behavior
- Must not remove or weaken the existing Step 1 re-tune flow for already-saved profiles -- not in scope
- Reversible, bounded blast radius -- prompt-only change to two already-shipped SKILL.md files, no schema or tool changes

## Acceptance

Selecting a template in Step 1a leads to a fast confirm-or-edit step (not a field-by-field walkthrough) before saving; an author who wants to adjust specific fields can do so in that single step, but is never marched through each field individually; fine-tuning an already-saved profile continues to work exactly as today via Step 1's re-tune path. Applied identically in /ps-voice and /ps-style.

## Blast Radius

cmd/pysar/assets/claude/skills/ps-voice/SKILL.md (Step 1a), cmd/pysar/assets/claude/skills/ps-style/SKILL.md (Step 1a)

## Reversibility

high
