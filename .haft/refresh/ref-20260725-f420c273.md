# Refresh Report

## Decision

prob-20260725-53b2d8ea

## Action

deprecate

## Reason

Acceptance criteria (A) treated 'how the agent forces correct understanding' as an open design question with multiple viable answers, including an explicit-confirmation-gate variant. Discussion with operator resolved this: audience/register/depth defaults are never intake's own judgment call -- they're read from the author's already-established voice/style profile (a children's-book author and a cybersecurity practitioner get materially different defaults for the identical input 'write something about AI', with zero questions asked). A blocking clarification question is reserved for genuinely degenerate input only, not vague-but-resolvable input. Superseded by a re-framed ProblemCard with this as a stated invariant rather than an open axis.

## Outcome

Artifact deprecated
