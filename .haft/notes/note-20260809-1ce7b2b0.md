# V1 is canonical Cursor package; Marketplace and site deeplink are discovery paths, not rival products

- Cursor Marketplace listing and a getpysar.com "Install in Cursor" deeplink are alternative discovery/install channels that expose the same V1 package — not separate packaging strategies.
