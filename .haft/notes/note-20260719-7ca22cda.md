# 

## Rationale

This is the same lesson recurring a third time in different surfaces (CLI messages, then Step-2 checklist formatting, now Step 6 silence) -- "skip X" is not the same instruction as "say nothing about X," and an executing agent will fill the gap with an explanation unless explicitly told not to. General takeaway for any future skill instruction: when the desired behavior is true silence, the instruction must say so explicitly and name a concrete example of the unwanted noise-message, not just describe the condition under which something should be skipped.
