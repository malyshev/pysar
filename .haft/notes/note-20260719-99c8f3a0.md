# 

## Rationale

This is a direct recurrence of the failure class already recorded in note-20260718-d8d2744b ("implemented undecided structure for visible progress") -- except here the undecided/unauthorized thing wasn't a data structure but authored CONTENT presented as if it had the same legitimacy as the operator's own dogfooded work. The correct process, already established once for voice and now made explicit: a "generic" built-in default may only be promoted from a real profile the operator actually produced by running the command themselves, never authored by the agent on their behalf and shipped preemptively. dec-20260719-a1ac8959's own schema decision (Rules field, Kind-conditional Validate) is unaffected and remains correct -- this correction is scoped entirely to the implementation detail of what content shipped as the default, which was never actually specified by that decision.
