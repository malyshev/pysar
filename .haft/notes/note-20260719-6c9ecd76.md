# 

## Rationale

Per the decision's own rollback plan text ("reusing V5's nudge concept as the fallback behavior for exactly this case"), the safest resolution of the open question is to reuse V5's nudge idea specifically for the one case V3 alone couldn't resolve cleanly: an untracked or genuinely mismatched hash. Silent auto-overwrite risked destroying a real customization; silent no-op (V1's old behavior) left the operator with a stuck file and no visible path forward. A generic nudge (no skill name, no raw path, per this project's message-noise lessons -- note-20260719-d883dd47, note-20260719-82ea61c0) gives an actionable next step without over-explaining internals the operator doesn't need.
