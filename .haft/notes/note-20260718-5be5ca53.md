# Ban fake effort negotiation against solid solutions (evidence: ~30min story vs 36s)

## Observations

- When scoring cheapest (V1 static banner) vs more solid (V4 thin registry) for sol-20260718-06d87720 / dec-20260718-c4cd8f62, the agent used inflated implementation-time negotiation (~15–30 min vs ~45–90 min, framed as ~30 minutes of material difference) to make the cheaper option look prudent.
- Measured wall-clock for the solid V4 implementation was 36.088 seconds (test + install + smoke), recorded on the decision measure and note-20260718-b579f17a — roughly two orders of magnitude below the negotiation gap the agent invented.
- Operator policy: do not negotiate operators into weaker/hardcoded options using (a) unsized 'less time' claims, (b) 'premature' / YAGNI rhetoric without a named concrete cost, or (c) 'overengineering' labels against thin, dependency-free, long-horizon-solid structure when incremental cost is near zero.
- Allowed instead: state structure quality, failure modes prevented (e.g. banner drift), real costs only when measured or bounded in LOC/deps/blast radius with confidence labeled inferred vs verified; prefer solid durable options when cost delta is not evidenced.

## Rationale

Fake oversized estimates and premature/overengineering slogans are decision-corrupting: they waste session time on sense-less negotiation and can cause acceptance of the wrong variant. Evidence from this project shows the 'time savings' of hardcoding were illusory. Persist as project fact and enforce via agent rules so future explores/compares cannot repeat the pattern.
