# Brief-frontmatter requires_research set by flag; draft skill owns the gate

## 1. Problem Frame

**Signal:** Shipped /ps is deliberately research-free: chain is intake → draft → staff-edit → sharpen → [--seo] → humanize → export. Research stays optional via separate /ps-research; intake/draft only do light ps-factcheck. Live dogfood showed a full /ps run can invent product capabilities and demo cases when sources stay thin (research_mode targeted, one Diátaxis URL) because nothing forces a real /ps-research pass. Operator wants an explicit opt-in flag on /ps — same surface pattern as --seo / --review — such that when the user adds --research, /ps-research MUST run as part of the pipeline after intake (before draft), not as a hope that intake/draft will ground enough on their own. Default /ps without the flag must remain research-free.

**Constraints:**
- Default /ps without --research must stay research-free (current contract)
- When --research is present, research is mandatory after intake — not best-effort, not skippable by agent judgment
- Reuse existing /ps-research skill via Skill tool; do not fork a second research implementation inside /ps
- Flag surface matches existing /ps opt-ins (--seo, --review): operator text flag parsed by skill prose, not a new Cobra CLI binary flag unless explore proves otherwise
- Must not silently reorder or break --seo-before-humanize (dec-20260804-e3234e50)
- Transformer Mandate: variants via explore; binding via manual /h-decide

**Acceptance:** With /ps --research <idea|@piece>, after intake has a piece (brief.md), the orchestrator invokes ps-research on that piece and save_research_bundle succeeds (research_mode full / non-empty sources.md as that skill defines) before any later stage that consumes the piece for drafting runs; without --research, /ps never invokes ps-research. Resume behavior is defined: a piece that already has full research does not re-run research unless force semantics are decided. Documented in ps/SKILL.md argument-hint and docs/pipeline.md. Verifiable by reading skill chain + a dogfood run-log showing intake then research then draft when the flag is present.

## 2. Decision

**Selected:** Brief-frontmatter requires_research set by flag; draft skill owns the gate

**Selection policy:** Eliminate if opt_in_surface_ok is false. Among survivors, maximize must_durability, then maximize future_gate_extensibility. dual_path_drift is observation only. Tie-break toward piece/MCP policy substrate over prose-only.

**Why selected:** Operator bound V5 for a hard --research gate. Durable requires_research on the piece (set when /ps --research runs) plus draft-owned refusal means the MUST survives agent prose skips, resume, and standalone /ps-draft — matching the dogfood failure mode where /ps never invoked research. Equal machine MUST to V2 with better long-term substrate for later stage gates. Default /ps without the flag stays research-free.


**Invariants:**
- Default /ps without --research never invokes /ps-research
- When --research is present, /ps invokes /ps-research after intake and before draft (resume skips only if research_mode is already full)
- requires_research true means save_draft_bundle refuses until research_mode is full
- requires_research is distinct from research_mode (none|targeted|full) — mode is outcome; requires_research is policy
- Reuse existing /ps-research via Skill tool; no forked research implementation inside /ps
- Do not break --seo-before-humanize ordering (dec-20260804-e3234e50)

**Admissibility:**

- NOT: Agent judgment that research can be skipped when --research was given

## 3. Rationale

**Counterargument:** V2 (skill flag + MCP save_draft precondition without piece frontmatter) delivers the same hard draft block with less schema surface — a new brief field is another carrier that can drift from research_mode (none/targeted/full) and confuse operators who already think research_mode is the policy switch.

**Selected variant weakest link:** requires_research can be set or cleared incorrectly (intake/orchestrator forgets to persist the flag, or legacy pieces lack the field) so the hard gate never arms; agents may also invent a soft bypass by editing brief.md outside MCP.

**Rejected alternatives:**
