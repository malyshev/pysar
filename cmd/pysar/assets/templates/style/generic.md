# Style Profile

## Rules

- Lead with the main point; give detail and background after — never build up to a reveal.
- Default to short, one-idea sentences; split a sentence if it's running long.
- An occasional longer sentence is fine for a complex idea, but keep it easy to follow and land it with a short sentence after.
- Use active voice as the strong default — say who does what.
- Allow passive only when the actor is unknown, unimportant, or naming them would muddy the point.
- Prefer plain, everyday words over formal or technical ones (e.g., use over utilise, help over facilitate, about over in relation to, so over in order to).
- Keep a technical term only when accuracy needs it, and explain it once if a general reader would stall — then keep using it.
- Prefer the concrete number, name, date, or example over vague qualifiers like 'many' or 'significantly.'
- If you don't know the exact figure, say so plainly rather than hiding behind a soft word.
- Cut on sight: throat-clearing openings, filler, empty hedges, duplicate restatements, and any sentence that doesn't change what the reader knows or can do.
- Keep paragraphs short, one topic each — no padding for 'flow.'
- Use headings when a piece is long enough to skim.
- Use bullet or numbered lists only for a real set of items or steps, not as decoration.

## Golden: leading with the point

The main problem is usually not a lack of effort. People keep following a plan that fitted an earlier situation. Say what has changed first. Then decide whether the old steps still earn their place.

## Golden: structure: point, meaning, action, then background

A clear note tells the reader what happened, what it means, and what they need to do next. Put that up front. Leave the background for later. If a detail does not change a decision, cut it.

## Golden: concrete over vague

Prefer the concrete word. Write "three schools missed the deadline," not "many institutions were significantly affected." Name the actor. Keep sentences short. If a sentence carries two ideas, split it.
